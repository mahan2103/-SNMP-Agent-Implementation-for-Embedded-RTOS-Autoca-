Internship Experience
During my internship at BEUMER Group (Airport Engineering), I worked on developing a lightweight SNMP (Simple Network Management Protocol) agent for the Autoca embedded system, which is used in airport logistics and automation.
🎯 Project Objective
The main goal of the project was to enable remote monitoring of Autoca devices using standard SNMP tools such as Paessler PRTG, while keeping the implementation efficient and suitable for an embedded RTOS environment.

🔧 My Responsibilities

Implemented a basic SNMPv1 agent in C
Developed UDP-based communication using port 161
Designed and implemented a custom MIB (Management Information Base)
Created logic to handle SNMP GET requests and responses
Integrated SNMP functionality into the main application (MyApp.c)
Implemented multi-threading for:

periodic heartbeat updates
continuous network listening


Tested and validated the system using SNMP testing tools (PRTG, SNMP Tester)


🧠 Key Learnings

Practical understanding of network protocols (SNMP, UDP)
Experience in embedded systems programming (RTOS environment)
Implementing thread-based architectures
Working with low-level packet encoding/decoding (BER)
Structuring real-time data using MIB design principles
Debugging and validating network communication systems


🚀 Outcome
The project resulted in a fully functional SNMP agent capable of providing real-time monitoring data such as:

System name
Device location
Heartbeat / uptime status

This enabled integration of Autoca devices into central monitoring systems, improving visibility and diagnostics in industrial operations.
